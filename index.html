Erste Schritte

📲 1. Als App installieren:
• Android / Chrome: Tippe oben rechts auf die 3 Punkte ➔ „App installieren“.
• iPhone / Safari: Tippe unten auf Teilen ios_share ➔ „Zum Home-Bildschirm“.
🌐 2. Spiele laden:
Wechsle auf der Startseite auf „Online-Store“ und lade die gewünschten Missionen mit einem Klick in deine Bibliothek.
🔗 3. Spiel mit Freunden teilen:
Klicke im Spielmenü auf „Link zum Spiel teilen“ und schicke den Link per WhatsApp. Das Spiel startet bei deinen Freunden sofort!

science Über dieses Projekt

escape.labs ist eine experimentelle Plattform für interaktive Outdoor-Escape-Games, Rallyes und persönliche Abenteuer.

Teil von forester.labs:
Dieses Projekt ist Teil von forester.labs – einer privaten Sammlung kleiner Web-Apps, Tools und Widgets, die von Marco Förster gebaut werden.
